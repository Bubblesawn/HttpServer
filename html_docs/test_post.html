测试说明

  • POST 请求：表单数据将在请求体中发送，不会在 URL 中显示
  • GET 请求：参数将附加在 URL 后面，如 ?q=关键词&category=分类
  • URL 编码：支持中文和特殊字符的自动编码/解码
  • Content-Type：服务器会根据 Content-Type 正确解析表单数据
